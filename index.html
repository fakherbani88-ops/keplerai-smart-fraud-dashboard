Présentation de l'application

KeplerAI est une application basée sur le Machine Learning qui permet d'analyser les transactions bancaires et d'identifier les opérations potentiellement frauduleuses.

Les principales tâches de l'application

  • Saisir les informations d'une transaction bancaire.
  • Analyser le montant de la transaction.
  • Examiner l'ancien et le nouveau solde.
  • Identifier la catégorie de transaction.
  • Utiliser les modèles de Machine Learning.
  • Prédire si une transaction est frauduleuse.
  • Afficher le résultat de la détection.
